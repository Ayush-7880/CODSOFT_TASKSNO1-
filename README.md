# CODSOFT AI Internship - Task 1

## Rule-Based Chatbot

A simple rule-based chatbot created for the Artificial Intelligence internship task.

The chatbot uses predefined rules, conditional statements, and basic pattern matching to identify user queries and provide appropriate responses.

## Features

- Greeting responses
- Simple chatbot introduction
- Basic conversation
- AI-related response
- Common question handling
- Help command
- Goodbye/exit handling
- Unknown-input fallback response

## Technologies Used

- Python
- Conditional statements
- String handling
- Basic pattern matching

## Project Structure

```text
CODSOFT_TASK1/

```

## How to Run

```bash
python chatbot.py
```

## Example

```text
You: Hello
Bot: Hello! How can I help you?

You: What is your name?
Bot: I'm a simple rule-based AI chatbot. How can I help you?

You: What is AI?
Bot: Artificial Intelligence (AI) is the field of creating systems that can perform tasks that normally require human intelligence.

You: Bye
Bot: Goodbye! It was nice talking with you.
```

## Learning Outcome

This project demonstrates how a basic conversational system can use predefined rules and conditional logic to identify user inputs and generate appropriate responses.
